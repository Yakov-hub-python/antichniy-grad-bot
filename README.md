# 🏛️ Античный Градоначальник — 1.6.2

Telegram-игра на Node.js + Telegraf.

## Запуск

1. Установи Node.js 18+.
2. Скопируй `.env.example` в `.env`.
3. Заполни `BOT_TOKEN` и при необходимости `ADMINS`.
4. Установи зависимости:

```bash
npm install
```

5. Запусти:

```bash
npm start
```

## Что исправлено в этой сборке 1.6.2

- Прогрессирующие личные боссы: следующий босс становится сильнее после победы.
- Автоматический бой с раундом раз в 1 секунду.
- Удалено создание старого глобального босса.
- Армия приведена к единому источнику данных `user.army`.
- Старые `soldiers` автоматически мигрируют в мечников и остаются совместимым общим счётчиком.
- Бонусы ветки армии реально участвуют в бою: урон, защита, снижение потерь и бонус урона по боссу.
- Кузница больше не увеличивает урон при каждом просмотре/сборе дохода.
- Экономические бонусы централизованы.
- Бонус продаж экономики 5 уровня работает на рынке.
- Комиссия рынка соответствует уровням экономики.
- 14 уровень экономики действительно даёт +2 слота порта.
- 15 уровень экономики даёт 10% скидку на покупки рынка.
- Ресурсы портового лота резервируются при выставлении.
- При отмене или истечении лота ресурс возвращается продавцу.
- Лимит активных лотов игрока зависит от экономики.
- Просмотр города больше не списывает еду, налог или солдат: расчёт дохода поддерживает режим preview.
- Кнопка дохода в меню показывает оставшееся время.
- Интервал обычного сбора — 20 секунд, VIP — 15 секунд.
- `/guide` расширен: ресурсы, формулы, здания, экономика, армия, боссы и торговля.
- `/help` синхронизирован с реальными командами.
- Ошибка Telegram 429 теперь показывает `retry_after`, если Telegram его передал.

## Основные команды

- `/start` — начало игры
- `/menu` — главное меню
- `/city` — город
- `/build` — строительство
- `/income` — собрать доход
- `/guide` — подробный гайд
- `/tutorial` — обучение
- `/branch` — ветви развития
- `/army` — армия
- `/hire <количество>` — нанять мечников
- `/boss` — текущий личный босс
- `/market` — рынок
- `/port` — порт

## Важно

Не добавляй `.env` с настоящим токеном в GitHub или публичный архив. Используй `.env.example` для передачи проекта.
